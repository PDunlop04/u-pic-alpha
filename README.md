# U-pic

A single-file browser game prototype set on a UVic-inspired campus map. Solve picture-word puzzles to unlock campus buildings.

## Run locally

Open `index.html` in a browser. If your browser restricts local-file behavior, start a local web server from this folder:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

Progress and audio preferences are stored in the browser's local storage.
